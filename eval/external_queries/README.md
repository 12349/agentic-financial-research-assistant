# External Query Dataset

## Overview
This directory contains an independently generated evaluation set of 50 financial queries designed to test cross-distribution robustness and avoid prompt-author co-adaptation.

## Generation Details
- **Generator Model**: `llama3.1:8b` (Meta / Llama family; different vendor family from primary evaluation models)
- **Quantization**: Q4_K_M
- **Temperature**: 0.0
- **Seed**: 42
- **Prompt**: See `generation_prompt.txt`
- **Date**: 2026-10-02
- **Hardware**: Apple M4 (Mac mini 2024, 16 GB unified memory, macOS 27.0)

## Stated Methodological Limitations
1. **Model Generation**: These queries were generated by a language model (`llama3.1:8b`), not by a human professional financial analyst.
2. **Independence Scope**: They satisfy the requirement of independence across model vendor families (Meta/Llama vs. Alibaba/Qwen), but do not constitute human rater independence.
3. **Labels**: Labels were verified against the standardized tool-routing rubric.
